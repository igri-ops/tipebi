# HVAC — დანადგარის ტიპის ამოცნობა

ინტერაქტიული ქართული ინსტრუქცია HVAC დანადგარის ტიპის დასადგენად.

**საიტი:** https://igri-ops.github.io/tipebi/

## განახლება
ცვლილებები შეიტანეთ `index.html`-ში და ატვირთეთ `main` შტოში. GitHub Actions ავტომატურად გამოაქვეყნებს განახლებულ ვერსიას.

> შენიშვნა: BTU/h და kW აღნიშვნები ზოგადად არ არის სპლიტისა და VRF/VRV-ის უნივერსალური განმასხვავებელი კრიტერიუმი. მოცემული კითხვარი ორგანიზაციის სამუშაო კლასიფიკაციის სქემას ასახავს.
